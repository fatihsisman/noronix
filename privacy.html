Türkçe

YouTube API Hizmetleri

noronix uploader ("uygulama"), noron.ix'in kendi ürettiği kısa videoları noron.ix'in kendi YouTube kanalına ve Instagram hesabına yüklemek için kullanılan kişisel bir otomasyon aracıdır. Uygulamayı yalnızca hesap sahibi kullanır.

  • Erişilen veriler: Uygulama, YouTube API Hizmetleri aracılığıyla yalnızca hesap sahibinin kendi kanalına video yükler, video başlığı/açıklaması/etiketlerini ayarlar, kendi videosuna yorum ekler ve kanal adını/kimliğini okur.
  • Kullanıcı verisi: Üçüncü kişilerin hiçbir kişisel verisi toplanmaz, saklanmaz, işlenmez veya paylaşılmaz.
  • Saklama: OAuth yetkilendirme token'ı yalnızca hesap sahibinin kendi şifreli ortamında (GitHub Secrets) saklanır ve başka hiçbir yere aktarılmaz.
  • Paylaşım: Veriler satılmaz, reklam için kullanılmaz, üçüncü taraflarla paylaşılmaz.
  • Silme: Uygulama YouTube API Hizmetlerinden aldığı hiçbir veriyi kalıcı olarak saklamaz; yalnızca yüklenen videonun kimliği yayın geçmişinde tutulur. Erişim iptal edildiğinde veya talep edildiğinde token ve bu kayıtlar 7 gün içinde silinir. Silme talebi için aşağıdaki iletişim kanallarını kullanabilirsiniz.
  • Erişimi iptal etme: Uygulamanın erişimi her an Google hesap izinleri sayfasından kaldırılabilir.

Uygulama YouTube API Hizmetlerini kullanır. Bu kullanım YouTube Hizmet Şartları ve Google Gizlilik Politikası'na tabidir.

English

YouTube API Services

noronix uploader is a personal automation tool used by noron.ix to upload its own short videos to its own YouTube channel and Instagram account. Only the account owner uses it.

  • Data accessed: Through the YouTube API Services, the app only uploads videos to the owner's own channel, sets their title/description/tags, posts a comment on the owner's own video, and reads the channel name/ID.
  • User data: No personal data of any third party is collected, stored, processed or shared.
  • Storage: The OAuth authorization token is stored only in the owner's own encrypted environment (GitHub Secrets) and is not transferred anywhere else.
  • Sharing: Data is not sold, not used for advertising, and not shared with third parties.
  • Deletion: The app does not persistently store any data obtained from the YouTube API Services; only the ID of each uploaded video is kept in the publishing log. When access is revoked or on request, the token and these records are deleted within 7 days. Deletion requests can be sent via the contact channels below.
  • Revoking access: Access can be revoked at any time at Google account permissions.

This app uses YouTube API Services. Use is subject to the YouTube Terms of Service and the Google Privacy Policy.
